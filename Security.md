# Security Policy

Atlas AI is a personal learning project. Even so, security issues are taken seriously.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting
(**Security → Report a vulnerability**) on this repository. Include steps to reproduce and the
impact you observed. You can expect an acknowledgement within a few days.

## Scope

- This repository (`atlas-ai-web`) and its deployed preview and production URLs.
- Backend issues belong to `atlas-ai-api`.

## Out of scope

- Denial-of-service and volumetric attacks.
- Findings that require a compromised device or browser.
